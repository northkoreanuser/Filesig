SigTool

개요
SigTool 은 RSA-SHA512 서명으로 배포 파일의 무결성을 보장하는 도구입니다.

서명자는 로컬의 private.pem 으로 파일에 서명하고, 서명 파일({SHA512}.sig)을 GitHub 레포에 업로드합니다. 검증자는 이 페이지에서 파일을 드래그하는 것만으로 서명을 확인할 수 있습니다. 개인키는 서명자 PC 에만 존재하며, 이 페이지와 레포에는 공개키(public.pem)만 올라갑니다.
검증자
▸ Verifier — 파일을 받은 사람
검증에 필요한 것은 없습니다. 이 페이지를 열고 확인할 파일을 드래그하면 끝입니다.

내부적으로는 파일의 SHA-512 해시를 계산한 뒤, 아래 경로에서 같은 이름의 {SHA512}.sig 파일을 가져와 공개키로 검증합니다:
—
{SHA512}.sig 파일이 없으면 "미서명 파일"로 표시됩니다. 파일이 조금이라도 변조됐다면 서명 불일치로 실패합니다.
서명자
▸ Signer — 파일을 배포하는 사람
1. 준비 (최초 1회)
키 생성 탭에서 private.pem 과 public.pem 을 생성합니다. 두 파일을 SigTool 과 같은 폴더에 둡니다.
📁 같은 폴더   ├── SigTool ← 실행 파일   ├── private.pem ← 절대 공개 금지   └── public.pem
public.pem 은 레포 루트에 한 번만 업로드합니다. private.pem 은 절대 업로드하지 마세요.

2. 서명
SigTool 을 실행하고 서명할 파일을 드래그합니다. 같은 폴더 안에 Filesig/ 폴더가 생성되고 {hash}.sig 파일이 저장됩니다.

3. 업로드
생성된 {SHA512}.sig 파일을 아래 경로에 업로드합니다:
—

Filesig/ 폴더가 없는 경우
레포에 Filesig/ 폴더가 없으면 업로드할 수 없습니다.
GitHub 웹에서 빈 파일을 커밋해 폴더를 먼저 만드세요:
— → Add file → Create new file → 파일명에 Filesig/.gitkeep 입력 → Commit
폴더 생성 후 {SHA512}.sig 파일을 업로드하면 즉시 검증이 활성화됩니다.
전체 흐름
① 키 생성 탭 → private.pem / public.pem 생성 ② 두 파일을 SigTool 과 같은 폴더에 배치 ③ public.pem → 레포 루트에 업로드 (최초 1회) ④ SigTool 실행 → 배포할 파일 드래그 → Filesig/{hash}.sig 생성 ⑤ {SHA512}.sig 파일 → 레포 Filesig/ 폴더에 업로드 ⑥ 검증자가 이 페이지에서 파일 드래그 → 자동 검증
